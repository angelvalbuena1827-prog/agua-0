Un sitio web es un mundo

Una página web puede parecer solamente una pantalla, pero también puede ser un lugar.

¿Qué entendí de Chia Amisola?

Después de leer a Chia Amisola, empecé a pensar los sitios web como espacios de interacción que podemos construir como queramos. No hay límites para lo que podemos crear en ellos, además son espacios que otras personas pueden habitar y con quienes podemos interactuar según la infraestructura propuesta, que nosotros como creadores, proponemos.

Un sitio web no es solamente un lugar para organizar información. También puede tener una forma de existir, una atmósfera y una manera particular de relacionarse con quien lo visita.

Por eso me llamó la atención pensar que hacer una página web también es construir un pequeño mundo, con características propias, pensado por nosotros mismos hasta el punto de que el sitio pueda hablar incluso de quiénes somos.

Algunas ideas que me quedaron

  • Un sitio web puede ser un mundo.
  • También puede ser un espacio que habitamos.
  • Su forma también comunica una manera de pensar.
  • La persona que entra también transforma la experiencia.
